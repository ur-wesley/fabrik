# Spec: Pure Go CLI Consolidation & TS Stack Retirement

## Summary
In accordance with issue `cli-04y` ("Remove src/ and migrate repository to pure Go CLI"), Fabrik is transitioning from a hybrid TypeScript/Bun/shell codebase to a **pure Go CLI tool** (`github.com/ur-wesley/fabrik/cli/cmd/fabrik`).

The legacy TypeScript Pi extension (`src/`), Bun E2E test suite (`e2e/`), and root Node/Bun toolchain files (`package.json`, `bun.lock`, `tsconfig.json`, `oxlint`, `oxfmt`, `index.ts`) are officially retired and removed.

The remaining work is to complete the consolidation:
1. Remove all retired TypeScript/Bun files and directories.
2. Fix the two remaining test issues in the Go CLI test suite (`cli/internal/installer` prompt hang, `cli/internal/tmpl` template drift).
3. Align all documentation (`README.md`, `PLAYBOOK.md`, `AGENTS.md`, `CLAUDE.md`) to the pure Go architecture.
4. Establish Go-native quality gates (`go test ./...`, `go vet ./...`, `go build ./cmd/fabrik`).

## Architecture Post-TS-Removal
- **Core Binary**: Go CLI located in `cli/` compiled directly to native binaries for Windows (`amd64`), Linux (`amd64`), and macOS (`arm64`).
- **Release Automation**: `.github/workflows/release-cli.yml` compiles binaries directly using `cli/package.json` for version stamping.
- **Client App Wiring**: Thin shims generated by `fabrik init` for Cursor (`.cursor/rules/*.mdc`, `.cursor/agents/*.md`), OpenCode (`opencode.json`), and Pi (`.pi/skills/*.md`, `.pi/agent/agents/*.md`).
- **Hub Content**: Embedded in the compiled binary (`cli/internal/tmpl/`), inspected via `fabrik show <key>`. On-disk `.fabrik/` contains only `config.yaml`, `docs/`, `specs/`.

## Key Actions

### 1. Delete Retired TS Stack Files
- Remove directory `src/` (legacy TS Pi extension).
- Remove directory `e2e/` (legacy Bun e2e runner).
- Remove root toolchain files:
  - `package.json`
  - `bun.lock`
  - `tsconfig.json`
  - `tsconfig.tsbuildinfo`
  - `.oxlintrc.json`
  - `.oxfmtrc.json`
  - `index.ts`
  - `.beads.gate.lock`

### 2. Fix Go CLI Test Suite
- **Installer Prompt Hang (`cli/internal/installer`)**:
  - Add `Confirm func(string, bool) bool` to `installer.Deps` defaulting to `ui.Confirm`.
  - Add test runner guard in `ui.Confirm` to prevent interactive BubbleTea prompts when testing.
  - Set `Yes: true` in `TestSetupRepoInitBeforeWorkflowNote`.
- **Template Drift & Repoint (`cli/internal/tmpl`)**:
  - In `tmpl_test.go`, update `pairs` to verify sync against `install/templates/hub/*` instead of deleted `.fabrik/*` files.
  - Synchronize `cli/opencode.json` with embedded `opencode.json`.

### 3. Documentation & Quality Gate Updates
- **`README.md`**:
  - Remove Pi extension npm install instructions (`pi install git:...`).
  - Remove `bun run test` / `bun run test:e2e` scripts.
  - Document Go CLI commands and `go test ./...`.
- **`PLAYBOOK.md`**:
  - Remove shell scripts and Bun references. Document Go CLI workflow (`fabrik setup`, `fabrik init`, `fabrik run`, `fabrik loop`).
- **`AGENTS.md` & `CLAUDE.md`**:
  - Set build, test, and backpressure commands to `cd cli && go test ./...`.
  - Correct `CLAUDE.md` line 23 memory rule to align with Engram (`mem_save`, `mem_session_summary`) instead of `bd remember`.
- **`.gitignore`**:
  - Clean up Node/Bun artifacts, ensure Go binaries and build artifacts are properly ignored.

## Success Criteria
- Zero TypeScript, Bun, or npm files at repository root (except `cli/package.json` which is version metadata for GitHub Actions).
- `cd cli && go test ./...` passes 100% across all packages without timeouts or hangs.
- `cd cli && go vet ./...` reports 0 issues.
- `cd cli && go build ./cmd/fabrik` succeeds cleanly.
- All documentation is unified, accurate, and contains zero conflicting instructions.
